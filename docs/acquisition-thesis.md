# Acqui-hire (買収・人材獲得) 仮説と戦略

## 1. なぜGoogleが本プロジェクト(whisper-edge)を買うのか

Googleは現在、生成AIの波においてインフラストラクチャのコスト爆発とプライバシー規制のジレンマに直面している。
本プロジェクトは、**「クラウドのGPUリソースを一切消費せず、ユーザーのエッジデバイス(ブラウザ)上で高度な音声認識を完結させる技術」**を実証するものであり、Googleの抱える以下の経営的・技術的課題を直接的に解決する。

1.  **推論コストの劇的な削減:** Meetのリアルタイム字幕や議事録作成をクラウドLLM/音声モデルで処理すると膨大なAPIコストがかかるが、これをユーザーのローカルGPU(WebGPU)にオフロードできる。
2.  **E2EE（エンドツーエンド暗号化）との互換性:** 企業向けの最高機密会議において、音声データをGoogleのサーバーに送信することなく高度な議事録・要約機能を提供可能になる。
3.  **ChromeOSエコシステムの強化:** Chromebookなどの低スペック端末でも動作する極限まで最適化されたWASM/WebGPU AIライブラリは、ChromeOSの優位性を高める。

## 2. ターゲットチームと現状の課題

*   **Google Meet チーム:**
    *   *既存プロダクト:* Meetのライブキャプション（現在サーバーサイド処理メイン）。
    *   *課題:* 全ユーザーの音声をサーバーでリアルタイム処理するための莫大なインフラコストと、ネットワーク遅延による字幕表示のラグ。
*   **Chrome / Web Platform チーム:**
    *   *既存プロダクト:* Chrome内蔵AI (Gemini Nano)、Live Caption。
    *   *課題:* WebGPUやWASMの実用的なキラーユースケースの不足。開発者向けの実装リファレンスの必要性。
*   **Google Workspace チーム:**
    *   *既存プロダクト:* Google Docs (音声入力)。
    *   *課題:* オフライン状態や低帯域ネットワーク環境下での音声入力の品質低下。

## 3. 過去の類似買収事例から見る勝ち筋

*   **Galileo AI / Hume AI 等の音声・UI系AIスタートアップ:** 特定のバーティカルなAI技術や感情分析などの「特化型エッジ/クラウドAI技術」を評価しての買収。
*   **Cameyo (2024年):** ChromeOSへの仮想化技術のネイティブ統合を目的とした買収。
*   *示唆:* Googleは「Chrome / OSにネイティブ統合することで、競合（Microsoft Teams/Windows）に対する強力なMoat（堀）になる技術と人材」を高く評価する。単なるSaaSの買収ではなく、**基盤技術（SDK/WebGPU最適化）のAcqui-hire**としてアプローチする。

## 4. 評価される技術の堀（Moat）

単なるOpenAI Whisper APIのラッパーは価値がゼロである。本プロジェクトがGoogleのエンジニアに「これを一から内製すると数ヶ月の工数がかかる」と思わせる技術的Moatは以下の4点に集約される。

1.  **WebGPU/WASMのメモリ・パイプライン極限最適化:** ONNXのINT8量子化だけでなく、動的なテンソルシェイプの最適化、KVキャッシュのフラッシュ戦略によるメモリリークの完全防止。
2.  **VAD（有音検知）のスマート統合:** Silero VADをAudioWorklet内で動かし、会議特有の「タイピング音」「咳」などを弾き、本当に必要な音声チャンクのみを推論エンジンに流す省電力ルーティング。
3.  **MV3 Offscreen制約の完全突破:** Chrome拡張における最新のManifest V3制約下での、最も効率的なバックグラウンド音声キャプチャと推論アーキテクチャのベストプラクティスの確立。
4.  **ネットワーク・ゼロの起動速度:** IndexedDBを用いたモデルのチャンク保存と並列ロードによる、2回目以降の「ゼロ秒起動」の実装。

    *   「Zero-server-cost Whisper on WebGPU」としてTrendingを狙う。
2.  **Chrome Web Storeでのトラクション (ターゲット: プロダクトマネージャー):**

    *   Product Huntにローンチし、初期MAU 10,000人 / CWS評価4.5以上を達成し、プロダクトとしての需要を証明する。
